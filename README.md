# Functional Analysis and PDE Notes

基于 Haim Brezis 教材整理的泛函分析学习笔记。当前笔记工程主要整理紧算子与谱理论内容；章节源文件位于 `chapters/`，主文件为 `Brezis_notes.tex`，排版设置位于 `Brezis_preamble.tex`。

## 编译

使用 XeLaTeX 编译主文件：

```text
xelatex Brezis_notes.tex
```

## 参考书

Haim Brezis, *Functional Analysis, Sobolev Spaces and Partial Differential Equations*, 1st ed., Springer, Universitext, 2011. DOI: [10.1007/978-0-387-70914-7](https://doi.org/10.1007/978-0-387-70914-7).

本项目笔记按章节持续整理，并非教材的替代品。书目信息见 [Springer 官方页面](https://link.springer.com/book/10.1007/978-0-387-70914-7)。
